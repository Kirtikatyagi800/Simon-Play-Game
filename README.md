# 🎮 Simon Says Memory Game

A fun and interactive memory game built using **HTML, CSS, and JavaScript**. Test your memory by remembering and repeating the color sequence as the game gets progressively harder.

## 🌐 Live Demo

[Play Simon Says Game](https://kirtikatyagi800.github.io/Simon-Play-Game/)

## ✨ Features

- Interactive four-color game interface
- Random color sequences
- Increasing difficulty with every level
- Visual feedback for game and player moves
- Game-over detection and score display
- Responsive, simple user interface

## 🛠️ Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling, layout, and visual effects
- **JavaScript** – Game logic, sequence generation, and user interaction

## 🎯 How to Play

1. Open the [live game](https://kirtikatyagi800.github.io/Simon-Play-Game/).
2. Press any key to start.
3. Watch the color sequence carefully.
4. Click the colors in the same order.
5. Each successful round adds another color to the sequence.
6. Continue as long as you can remember the sequence!
